# Tirth (तीर्थ) – Sacred Indian Pilgrimage Portal

An autonomous, full-stack, production-grade pilgrimage discovery and parikrama guidance platform built with **Next.js 16 (App Router)**, **React 19**, and **Tailwind CSS**.

The portal serves pilgrims and devotees exploring India's ancient sacred circuits—most notably the **84 Kos Braj Parikrama (Mathura-Vrindavan)** and the **84 Kos Naimisharanya Parikrama (Sitapur & Hardoi)**—complete with interactive route maps, 11-day sequential parikrama stops (पड़ाव), 20 sacred shrines, and a robust 12-language multilingual system.

The production codebase is located in `/tirth-portal`.

## Quick Start

```bash
cd tirth-portal
npm install
npm test
npm run build
npm run start
```
